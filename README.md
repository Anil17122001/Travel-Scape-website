🌍 Travel Scape – Responsive Travel Website

A modern, responsive, and visually stunning travel website built using HTML, CSS, and JavaScript.
This project showcases beautiful travel destinations, dark mode, sliders, animated sections, and a fully responsive UI — perfect for portfolios and resume projects.

🚀 Features

✔ Fully Responsive Layout
✔ Modern UI/UX Design
✔ Swiper Slider Integration
✔ Smooth Scroll Animations
✔ Dark Mode Toggle
✔ Discover Section with Auto Slider
✔ Places Section with Ratings & Prices
✔ Video Play/Pause Feature
✔ Newsletter Subscription Form
✔ Clean Folder Structure
✔ SEO-Friendly HTML
